مستوى 3: القرارات (If / Else)

⭐ النقاط: 0 / 50

📖 شرح الشروط

تستخدم الشروط لجعل البرنامج يتخذ قراراً حسب البيانات.

كيف تعمل if و else؟

إذا كان الشرط صحيحاً، ينفذ Python الكود الموجود بعد if. وإذا كان الشرط غير صحيح، ينفذ الكود الموجود بعد else.

age = 20 if age >= 18: print("أنت بالغ") else: print("أنت قاصر")

if تعني إذا، وelse تعني وإلا. المسافة قبل print مهمة لأنها توضح الكود الموجود داخل الشرط.

علامات المقارنة

x == 5 # يساوي x > 3 # أكبر من x < 3 # أصغر من x >= 3 # أكبر من أو يساوي x <= 3 # أصغر من أو يساوي x != 5 # لا يساوي

بعد فهم الشرح، حل التطبيقات الخمسة. كل إجابة صحيحة تمنحك 10 نقاط.

التطبيق 1: هل الشخص بالغ؟

اكتب شرطاً يفحص إذا كان العمر أكبر من أو يساوي 18، ويطبع أنت بالغ أو أنت قاصر.

التطبيق 2: هل اللاعب فاز؟

افحص إذا كانت النتيجة أكبر من أو تساوي 80، واطبع فزت! أو حاول مرة أخرى.

التطبيق 3: هل الرقم موجب؟

افحص إذا كان الرقم أكبر من صفر، واطبع موجب أو سالب أو صفر.

التطبيق 4: هل اللاعب هو أحمد؟

افحص إذا كانت قيمة player تساوي "أحمد"، واطبع مرحباً بطلنا أو من أنت؟.

التطبيق 5: هل الطالب ناجح؟

افحص إذا كانت الدرجة أكبر من أو تساوي 60، واطبع ناجح أو راسب.
